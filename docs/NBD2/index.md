# NBD User Guide

## What is NBD?

**NBD (Next Best Decision)** is a data-driven investment and mix-setting tool designed for analysts, planners, and marketing managers. It combines advanced econometric modeling with reinforcement learning to help you make optimal media investment decisions.

NBD is a specialist tool, but is designed to be user-friendly enough for anyone responsible for investment allocation and media planning. The suggested defaults ensure that first-time users can start using NBD quickly and learn the more advanced features over time.

## Who is NBD For?

- **Analysts** - Understand media contribution and model performance across markets
- **Planners** - Create and optimize media plans based on data-driven recommendations
- **Marketing Managers** - Make strategic investment decisions backed by MMM insights

## Two Primary Functions

### 1. [Insights](insights.md)

The Insights module helps you understand past media performance:

- **Geographic Insights** - Compare media efficacy across markets
- **Media Touchpoint Insights** - Visualise contribution, response curves, and ROI by channel
- **Global Meta-Analysis** - Understand overall effectiveness at a global scale
- **Market Analysis** - Drill down into market-specific dynamics

### 2. [Scenario Planning](scenario-planning.md)

The Scenario Planning module helps you plan future media investments:

- **[Generate New Plans](generate-plan.md)** - Create optimal media plans for specific timeframes and budgets
- **[Forecast Plans](forecast-plan.md)** - Predict KPI outcomes for existing media plans
- **[Optimise Plans](optimise-plan.md)** - Refine existing strategies to maximise impact

## Key Concepts

Before diving in, it's helpful to understand these foundational concepts:

- **KPI** - The business metric you're trying to maximize (e.g., transactions, brand awareness)
- **Market** - Geographic region (e.g., UK, US, Germany)
- **Channel** - Media touchpoint (e.g., Google Search, Facebook, TV)
- **Constraints** - Limits on how much spend can change (keeps plans realistic)
- **Benchmarks** - Historical or default spending patterns used for comparison
- **Response Curves** - How media impact changes with spend (diminishing returns)

For detailed definitions and concepts, see [Glossary](glossary.md).
