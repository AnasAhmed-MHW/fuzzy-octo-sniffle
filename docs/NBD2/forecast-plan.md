# Forecast a Plan

Use the Plan Forecaster when you have an existing media plan and want to predict its KPI performance.

## Step-by-Step

1. **Select Date Range** - The period your existing plan covers

2. **Choose KPI** - The metric you want to forecast

3. **Select Benchmark** - Optional comparison against historical patterns

4. **Enter Your Plan** - Input planned spend by channel and week

<!-- SCREENSHOT: Plan input form with channel/week grid for entering spend values -->

5. **Forecast** - NBD predicts the KPI outcome based on your MMM models

## Output

- **Forecasted KPI** - Expected performance of your plan
- **Contribution Breakdown** - How much each channel is expected to contribute
- **Benchmark Comparison** - How your plan compares to alternatives

<!-- SCREENSHOT: Forecast results showing KPI prediction, contribution by channel, and comparison chart -->

## Use Cases

### Budget Approval
Show expected results to stakeholders before committing budget.

### Plan Comparison
Forecast multiple scenarios to choose the best approach.

### Reality Check
Validate if a manually created plan makes sense given your MMM models.
