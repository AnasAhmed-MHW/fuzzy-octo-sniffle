# S3 Bucket


The taxonomy checker assumes Adverity Datastreams are dropping data into the AWS Bucket.

Checker assumes the files are dropped into the client bucket under the `canonical/name` folder. 
With the {channel} as a folder. 

Example `canonical/name/meta`
